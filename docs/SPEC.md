# ファンタジー城下町 生成仕様 (SPEC)

## ゴール
Blender 5.1 のヘッドレス実行 (`blender -b -P scripts/generate_town.py`) で、
ミッドポリ品質のファンタジー城下町を **プロシージャル生成** し、
Unity で歩けるゲームに使える形 (FBX / GLB) でエクスポートする。

参考イメージ: プラハ・ブルージュ風の石畳ヨーロッパ旧市街 ＋ アニメ調ファンタジー城下町。

## 品質ターゲット
- 「ちょっとした3Dゲーム」レベルのミッドポリ。ローポリのスカスカ感は禁止。
- 一人称視点 (目線高さ 1.6m) で見栄えがすること。地面レベルのディテール優先。
- 総ポリゴン数の目安: 30万〜150万 tris(Unityでリアルタイム描画できる範囲)。

## 街の構成 (必須)
1. **中央の城**: 高台または街の奥に城。天守/主塔＋複数の尖塔、城壁。街のどこからでもランドマークとして見える高さ (60m+)。
2. **城下町**: 城の手前に広がる市街地。
3. **メインストリート**: 城門から街の入口まで通る長め (150m+) の大通り。緩やかなカーブがあると良い。
4. **市場広場**: 大通り沿いか城の手前に広場。噴水または井戸を中央に。屋台・樽・木箱を配置。
5. **街の外周壁**: 街全体を囲む城壁と門塔 (最低1つの大きな門)。

## 密度の制約 (最重要)
- 通り沿いの建物は **隣接** させる (連続したファサード)。建物間の隙間は 0 か、路地 (幅1.5〜3m) のみ。
- 街区 (ブロック) 単位で建物を詰めて配置。ローポリ時代の「ポツポツ配置」は禁止。
- 建物の階数は 2〜4 階でばらつかせ、屋根の向き・高さも変化をつける。

## 建物のスタイル
- ハーフティンバー様式 (白/クリーム壁 + 濃茶の木骨) を主体に、石造り建物を2〜3割混ぜる。
- 屋根: 切妻・寄棟を混在。テラコッタ / 濃緑 / スレート灰のバリエーション。
- 一人称で見えるディテール: 窓 (凹み or フレーム付き)、扉、1階の張り出し (jetty)、
  店の庇・看板、煙突。窓や木骨はテクスチャではなくジオメトリで表現する。
- 各建物はモジュラー生成 (パラメトリック) で、同じ見た目の建物が並ばないようにシード乱数で変化させる。

## 地面・小物
- 石畳の道 (大通り・路地)。地面はフラットで可 (Unityでの歩行を考慮し、段差は階段状に)。
- 街灯、樽、木箱、荷車、屋台、井戸/噴水、木 (広場・城まわり) を適度に散らす。
- 街の外は緩やかな地形 + 遠景の山 (背景用ローポリで可)。

## マテリアル・テクスチャ (改訂: 自前生成テクスチャを使う)
- **テクスチャ画像は自前でプログラム生成する** (ダウンロード素材は使用禁止)。
  Python (numpy等、またはピクセル直書き) で PNG を `textures/` に生成し、UV展開して適用する。
- 必要テクスチャ: 石畳 (道用)、漆喰壁 (汚し・ムラ入り)、石壁 (城・城壁用ブロックパターン)、
  屋根瓦 (テラコッタ/スレート/緑 の色替え)、木材 (木骨・扉・樽用木目)。各512〜1024px、タイリング可能なこと。
- ベースカラーテクスチャが GLB/FBX に同梱され Unity でそのまま見えること。
- 木骨・窓などのジオメトリ表現は維持した上で、面にテクスチャを乗せて情報量を上げる。
- パレット: クリーム壁 / 濃茶木骨 / テラコッタ屋根 / 石灰 / 深緑 / 金アクセント。

## 技術制約
- Blender 5.1 headless で完走すること。エラーで途中終了しない。
- 実行時間: 10分以内。乱数シードは固定 (再現性)。
- 命名: `Castle_*`, `House_*`, `Wall_*`, `Prop_*`, `Ground_*` のプレフィックス。
- コレクションで整理: Castle / Town / Walls / Props / Ground / Environment。
- エクスポート: `export/town.glb` (GLTF) と `export/town.fbx`。スケールは 1unit=1m、Z-up→Unity対応。
- レンダリング: Eevee で `renders/` に PNG (1920x1080) を出力:
  - overview (俯瞰全景)
  - main_street_fp (大通り一人称 1.6m)
  - plaza_fp (広場一人称)
  - castle_gate_fp (城門前一人称)
  - alley_fp (路地一人称)
- ライティング: Sun + World (空色)。夕方寄りの暖色か昼光。影を有効に。

## レビュー観点 (チェックリスト)
- [ ] 通り沿いのファサードが連続している (隙間なし)
- [ ] 一人称スクショで画面が「街」に見える (建物が視界の左右を埋める)
- [ ] 城がランドマークとして大通りの奥に見える
- [ ] 建物のバリエーション (高さ・色・屋根) が出ている
- [ ] 窓・木骨・庇がジオメトリで存在する
- [ ] ヘッドレスで完走し、GLB/FBX/レンダが全て生成される
